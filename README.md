# GTA Online Progression

Immerse players in GTA Online-style progression with missions, heists, businesses, and properties.

## Features

- Mission system with cooldown and rewards
- Heist system with cooldown and increased rewards
- Business system with upgradeable levels and profit multipliers
- Property system with rent and sale options
- Phone app interface for easy access to all systems

## Requirements

- FiveM server with ESX framework
- ox_lib, ox_inventory, and ox_target libraries

## Installation

1. Download the script from the [releases page](https://github.com/EnderDevelopment/gta-online-progression/releases)
2. Extract the files into your FiveM server's `resources` directory
3. Add `start gta-online-progression` to your server.cfg file

## Usage

### Commands

There are no commands for this script. Players interact with the systems through the phone app.

### Permissions

There are no special permissions required for this script. Players interact with the systems through the phone app.

## Configuration

The script can be configured through the `config.lua` file. The following options are available:

- `Config.Locale`: Set the language for the script
- `Config.Debug`: Enable or disable debug mode
- `Config.MissionCooldown`: Set the cooldown for missions in seconds
- `Config.MissionRewardMultiplier`: Set the reward multiplier for missions
- `Config.HeistCooldown`: Set the cooldown for heists in seconds
- `Config.HeistRewardMultiplier`: Set the reward multiplier for heists
- `Config.BusinessUpgradeCostMultiplier`: Set the upgrade cost multiplier for businesses
- `Config.BusinessProfitMultiplier`: Set the profit multiplier for businesses
- `Config.PropertyRentMultiplier`: Set the rent multiplier for properties
- `Config.PropertySaleMultiplier`: Set the sale multiplier for properties
- `Config.PhoneAppName`: Set the name of the phone app
- `Config.PhoneAppIcon`: Set the icon of the phone app
